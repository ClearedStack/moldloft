# Sample performance period allowance

Counts calendar days between two ISO-8601 dates and multiplies inclusive performance days by a made-up daily allowance. Every rule and number here is invented to exercise date inputs in the calculator template.

This is a static calculator. It is plain HTML, CSS and JavaScript with its
reference values bundled in. It runs entirely in the browser: there is no
server, nothing is stored, nothing is sent anywhere, and it works offline.

## What this tool does not cover

- Every rule, date range and rate here is fictional. Do not use the result for a real travel voucher, period of performance or contract claim.
- Counts calendar days on the proleptic Gregorian calendar and does not adjust for federal holidays or partial travel days.

## Use it

Open `index.html` in a browser, or serve this folder with any static file
server.

## Check it

Every worked example is a saved set of inputs with the exact results that must
come out.

- In a browser: open `tests/index.html`.
- With Node.js: `node tests/run.js` (no packages, no network).

Worked examples in this repository:

- Leap-year February span: 2024-02-15 through 2024-03-15 at 166.50 a day
- Common-year February span: 2025-02-15 through 2025-03-15 at 166.50 a day
- Same start and end date: one inclusive billable day

## Sources

1. Sample Rule 45.2(a) (fictional). Defines inclusive performance days as elapsed calendar days plus 1 (https://rules.example/sample-rule-45-2)
2. Sample Rule 45.2(b) (fictional). Multiplies inclusive performance days by the daily allowance rate

## Security

Each page carries this content security policy, and whoever serves the folder
should send the same value as a `Content-Security-Policy` header:

    default-src 'self'; connect-src 'self'; form-action 'none'

The pages load nothing from another site and contain no tracking or analytics.
